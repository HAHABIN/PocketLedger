# 轻松记账 / PocketLedger

离线 iPhone 记账项目。SwiftUI、Swift Charts、SQLite + GRDB，最低 iOS 16。无登录、无服务器、无自动云同步。

## 启动

1. 在 Mac 上使用 Xcode 15 或更新版本打开 `PocketLedger.xcodeproj`。
2. 等待 Swift Package Manager 下载 GRDB 6.29.3。首次解析依赖需要网络，应用使用不需要网络。
3. 选择 PocketLedger Scheme 和 iPhone 模拟器运行。
4. 真机运行时修改 Bundle Identifier，并在 Signing & Capabilities 中选择自己的开发团队。

## 当前实现

- 首页月份、账本筛选，收支结余、预算、搜索、编辑及删除交易。
- 支出、收入、转账、借入、借出、部分还款；借贷本金修改受已还金额约束。
- 多账户、信用卡欠款、账户流水、名称修改及余额差额调整。
- 周/月/年趋势、分类占比、账户及账本筛选。
- 多账本、默认账本、归档、重命名、空账本删除、月度预算。
- 明文 JSON 完整备份、覆盖/合并恢复、自动保存恢复前快照、CSV 导出。
- 分类增删、设备认证解锁、进入后台遮盖财务内容。

## 数据规则

所有金额为 Int64 分；账户初始余额加交易流水推导余额。负余额计入负债。借出未收回为应收资产，借入未还为负债；信用卡还款为账户转账。转账、借还款和余额调整不进入收入支出。账本负责统计，账户全局共用。支持人民币单币种。

SQLite 保存版本化完整数据快照，写入事务保证整体原子性。当前设计适用于个人小规模使用，大规模流水应迁移到规范化表和索引。合并导入遇到同ID不同内容直接取消，不自动选择任一版本。完整恢复校验通过后才覆盖；恢复前快照仅保留最近一次。

## 命令

```sh
swift test
xcodebuild -project PocketLedger.xcodeproj -scheme PocketLedger -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build
```

建议先在模拟器验证：新增账户→记录支出→账户转账→借出→部分收回→导出 JSON→修改一笔→覆盖恢复→重新启动确认数据保留。
