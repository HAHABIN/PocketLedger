## 与文档的实现差异

- 内部资金余额采用有符号统一表示，负债界面转换为正欠款；外部显示及净资产验算保持一致。
- 分类目前仍为有序名称列表；分类独立 ID、类型、停用和分类预算属于后续工作。
- 界面使用原生 List/Form 和珊瑚橙卡片，未逐像素复刻概念图；待真实设备逐屏验收。
- 数据库有关系表和索引，报表目前基于载入的内存状态聚合，尚未全部改为 SQL 聚合。
- 没有实现加密备份、通知提醒、商店图标及发布材料。
